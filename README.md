# C-Nodo-s
## Features
* **Node Creation & Dynamic Allocation:** Efficient memory allocation for custom data nodes.
* **Insertion & Deletion:** Functions for adding and removing nodes from linked structures.
* **Traversal & Visualization:** Console outputs showing internal node states and connections.
* **Stack (Pila) Operations:** LIFO (Last In, First Out) stack mechanics using custom node pointers.
* **Memory Cleanup:** Proper deletion of nodes to prevent memory leaks in C++.

---

## Technologies & Concepts

* **Language:** C++
* **Concepts:** Pointers, Dynamic Memory Allocation (`new` / `delete`), Structs / Classes, Linked Lists, Stacks.
* **Build Tool:** `g++` / GCC Compiler.
